# Müller-Brockmann Grid System

Objectif :
Créer des interfaces web premium, structurées, éditoriales et rigoureusement alignées.

Principes obligatoires :

- Grille 12 colonnes
- Baseline 8px
- Alignement strict des éléments
- Hiérarchie typographique forte
- Beaucoup d’espace blanc
- Composition asymétrique maîtrisée
- Typographie sans-serif moderne : Inter, Helvetica, Arial
- Texte aligné à gauche
- Design clair, rationnel, premium

Palette recommandée :

- blanc
- noir
- gris neutres
- une seule couleur d’accent

Interdictions :

- gradients violets ou bleus génériques
- design SaaS banal
- effets décoratifs inutiles
- surcharge visuelle
- éléments placés au hasard

Pour chaque page :

1. Construire une vraie grille visuelle
2. Aligner les sections sur les colonnes
3. Utiliser les espacements comme un outil de valeur perçue
4. Créer une impression premium dès le premier écran
5. Éviter les designs trop “template”

Le design doit donner une impression de maîtrise, de sérieux et de haut niveau.
