# UX Design

Objectif :
Créer des interfaces simples, claires et agréables à utiliser.

Principes obligatoires :

- Le visiteur doit comprendre l’offre en moins de 5 secondes
- Le parcours utilisateur doit être évident
- Chaque page doit avoir un objectif clair
- Chaque section doit guider vers l’action suivante
- Réduire au maximum les frictions
- Éviter les textes trop longs
- Utiliser des titres explicites
- Rendre les CTA visibles et compréhensibles

Structure UX recommandée :

1. Compréhension immédiate
2. Identification du problème
3. Présentation de la solution
4. Preuves de crédibilité
5. Explication simple du fonctionnement
6. Réassurance
7. Action claire

Règles :

- Un bouton principal par section importante
- Navigation simple
- Mobile first
- Pages rapides à scanner
- Pas d’éléments inutiles

Pour les formulaires :

- demander uniquement les informations nécessaires
- réduire le nombre de champs
- afficher clairement les erreurs
- confirmer l’action après envoi

L’interface doit être pensée pour un utilisateur pressé.
