# Performance Web

Objectif :
Créer des sites rapides, fluides et optimisés pour Vercel.

Priorités :

- chargement rapide
- images optimisées
- code propre
- composants légers
- animations maîtrisées
- bonne expérience mobile

Règles obligatoires :

- utiliser next/image pour les images
- éviter les bibliothèques inutiles
- limiter les animations lourdes
- éviter les vidéos trop lourdes en fond
- lazy loading quand nécessaire
- composants réutilisables
- éviter le code dupliqué

Core Web Vitals :

- LCP optimisé
- CLS minimal
- interaction rapide
- responsive fluide

Bonnes pratiques :

- privilégier Server Components
- charger le minimum de JavaScript côté client
- utiliser "use client" uniquement si nécessaire
- découper proprement les composants
- éviter les effets visuels inutiles

Le site doit paraître premium, mais rester rapide.
