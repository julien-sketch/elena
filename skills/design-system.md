# Design System

Style général :

- premium
- moderne
- professionnel
- haut de gamme

Interdictions :

- dégradés violets
- design générique SaaS
- animations inutiles
- ombres excessives

Typographie :

- Inter
- hiérarchie très marquée
- titres imposants
- textes courts

Mise en page :

- grille 12 colonnes
- grands espaces blancs
- asymétrie maîtrisée
- alignement rigoureux

Palette :

- blanc
- noir
- accent unique selon la marque

Objectif :

donner une impression de valeur élevée dès les 3 premières secondes.
