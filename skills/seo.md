# SEO

Objectif :
Créer des sites techniquement propres, lisibles par Google et optimisés pour la conversion.

Règles obligatoires :

- Une seule balise H1 par page
- Titres H2 structurés
- Metadata SEO complète
- Title clair et orienté recherche
- Description persuasive
- URLs propres
- Images optimisées
- Textes alternatifs sur les images importantes
- Structure HTML sémantique

Pour chaque page, prévoir :

- title
- description
- H1
- H2
- texte d’introduction clair
- contenu utile
- CTA

Bonnes pratiques :

- utiliser des mots-clés naturellement
- éviter le bourrage de mots-clés
- écrire pour l’humain avant Google
- créer des sections lisibles
- optimiser le temps de chargement

Pour Next.js :

- utiliser metadata dans App Router
- optimiser les images avec next/image
- éviter le JavaScript inutile
- privilégier les composants server quand possible

Le SEO ne doit jamais dégrader la qualité du design ou du message.
